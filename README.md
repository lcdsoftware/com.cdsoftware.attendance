## Description

This plugin provides a comprehensive system for managing employee attendance, shifts, and extra hours within iDempiere. It features integrations with various biometric devices (ZKTeco, Bioadmin) and REST servers, along with advanced logic for processing markings and assigning shifts.

## Dictionary & Data Models

### Windows & Tabs
- **Shift Management**: Configuration of entry/exit times per day of the week.
- **Markings**: Registry of raw markings from biometric clocks.
- **Attendance**: Processed summary of each employee's workday.
- **Attendance Devices**: Configuration of biometric terminals.

### Models (Tables)
- `GH_Shifts`: Shift header.
- `GH_ShiftsLine`: Detail of schedules, tolerances, and breaks per day.
- `HR_Attendance`: Consolidated daily attendance registry.
- `HR_AttendanceLine`: Detail of entry/exit and calculated hours.
- `I_Marking`: Interface table for marking imports.

## Prerequisites

- Java 11, commands `java` and `javac`.
- iDempiere 10
- Set `IDEMPIERE_REPOSITORY` env variable
- Dependencies: `joda-time`, `json`.

## Features/Documentation

### Packages
- `com.cdsoftware.lirion.attendance.process`: Marking processors, extra hour calculators, and importers.
- `com.cdsoftware.lirion.attendance.model`: Persistence logic for shifts and attendance.
- `com.cdsoftware.lirion.attendance.callout`: Permission validations and real-time hour calculations.
- `com.cdsoftware.lirion.attendance.util`: Template generators and SQL utilities.

### Processes

| Process | Parameters | Description |
|---------|------------|-------------|
| `ProcessAttendance` | N/A | Processes raw markings and converts them into attendance records based on the employee's shift. |
| `CalculateExtraHour` | `AttendanceDate`, `C_BPartner_ID`, etc. | Calculates diurnal, nocturnal, Sunday, and rest day extra hours. |
| `ImportAttendanceBioadmin` | Attachment | Imports markings from files generated by Bioadmin software. |
| `ImportAttendanceFromServerREST` | N/A | Synchronizes markings from a centralized REST server. |
| `AddMissingDates` | Date Range | Generates empty records for days without markings to facilitate administrative control. |

### Validations & Logic
- **Automatic Calculation**: The system automatically differentiates between normal working hours and different types of extra hours according to the payroll concepts configured.
- **Tolerances**: Supports configuration of grace minutes for late entries and early exits.

## Instructions

- Install the plugin and configure the devices in the "Attendance Devices" window.
- Define work shifts and assign them to employees in the Human Resources tab.
- Periodically run the "Process Attendance" process to consolidate information for payroll.
